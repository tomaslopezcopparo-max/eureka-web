Píxel de Meta y API de conversiones: cómo instalarlos paso a paso

La guía que usamos con nuestros clientes: qué es cada herramienta, cómo instalarla según tu web, qué eventos medir en una pyme y cómo comprobar que todo funciona.

Por Tomás López·18 de noviembre de 2026·9 min de lectura

Respuesta corta: el píxel de Meta es un código que mide desde el navegador lo que hace la gente en tu web después de ver un anuncio. La API de conversiones manda esos mismos eventos desde tu servidor o tu plataforma, así no se pierden por bloqueadores o cookies. Lo recomendable es usar los dos, conectados al mismo conjunto de datos y con deduplicación, y probarlos con la herramienta Probar eventos antes de lanzar campañas.

¿Qué es el píxel de Meta?

El píxel de Meta (antes píxel de Facebook) es un fragmento de código JavaScript que se instala en tu sitio web y le avisa a Meta cada vez que alguien hace algo importante: entra a una página, ve un producto, completa un formulario o compra. A cada una de esas acciones se la llama evento.

Con esos eventos Meta mide qué trajo cada anuncio, arma públicos para retargeting y aprende a quién mostrarle tus anuncios. Si el píxel mide mal, la campaña optimiza a ciegas.

Hoy, en el Administrador de eventos (Events Manager), Meta habla de conjuntos de datos: reúnen los eventos del píxel, de la API de conversiones y de otras fuentes. Su ID es el mismo número que antes llamábamos ID del píxel.

¿Qué es la API de conversiones de Meta y en qué se diferencia del píxel?

La API de conversiones de Meta (Conversions API o CAPI) es una conexión directa entre tu servidor, tu tienda online o tu CRM y Meta. Manda los mismos eventos que el píxel sin pasar por el navegador, así que no la frenan los bloqueadores ni las cookies.

Píxel de MetaAPI de conversiones

No son excluyentes. Meta recomienda usar las dos y que se complementen. En abril de 2026 Meta informó que los anunciantes que usan la API de conversiones para eventos web tuvieron, en promedio, un costo por resultado 17,8% menor que los que no la usan. Es un dato de la propia Meta.

¿Cómo instalar el píxel de Facebook paso a paso?

El primer paso es igual para cualquier sitio: crear el conjunto de datos. Necesitás acceso de administrador al portafolio comercial (Business Manager) de tu empresa.

  1. Entrá al Administrador de eventos desde Meta Business Suite y revisá arriba que estés en el portafolio comercial correcto.
  2. Hacé clic en Conectar datos, elegí Web y seguí.
  3. Poné un nombre claro, por ejemplo "Nombre de la empresa · Web", y creá el conjunto de datos.
  4. Meta te ofrece formas de conectarlo: integración de un socio (Tienda Nube, WordPress, Shopify y otras), instalar el código manualmente o configurar la API de conversiones. Elegí según tu caso, como vemos abajo.
  5. En la pestaña Configuración del conjunto de datos copiá el ID y activá la coincidencia avanzada automática, que suma datos como el email cuando el usuario los completa en un formulario.
  6. Asigná el conjunto de datos a tu cuenta publicitaria, así podés elegirlo al armar las campañas.

Opción 1: instalación manual en el código

  1. Elegí Instalar el código manualmente y copiá el código base.
  2. Pegalo dentro de la etiqueta <head> de todas las páginas del sitio. Con eso ya mide PageView.
  3. Agregá los eventos donde corresponda. Por ejemplo, en la página de "gracias" de un formulario: fbq('track', 'Lead');

Para la API de conversiones manual, en Configuración generás un token de acceso y un desarrollador programa el envío desde tu servidor. Es la opción más flexible y la que más trabajo técnico pide.

Opción 2: Tienda Nube

  1. En el administrador de Tienda Nube, entrá a Instagram y Facebook y hacé clic en Conectar con Meta (si ya estaba conectado, en Editar conexión).
  2. Elegí tu página, cuenta publicitaria, catálogo, píxel y portafolio comercial.
  3. Dejá activo el permiso de acceso a anuncios y estadísticas, y verificá el dominio de la tienda.

Con esa conexión, Tienda Nube activa la API de conversiones sola. Según su centro de ayuda, por ahora envía por API los eventos Agregar al carrito, Agregar información de pago y Comprar. Ojo: no es compatible con la API de conversiones Gateway de Meta. Si tenés las dos activas, hay que desconectar el Gateway.

Opción 3: WordPress

  1. Instalá el plugin oficial Meta pixel for WordPress, publicado por Facebook en el directorio de WordPress.
  2. Conectalo con tu cuenta y elegí el conjunto de datos que creaste.
  3. Revisá que tenga activa la API de conversiones: el plugin la incluye y manda eventos como Lead, ViewContent, AddToCart, InitiateCheckout y Purchase.

Si tu tema ya tiene un campo para el ID del píxel, no lo completes además del plugin: lo instalarías dos veces.

Opción 4: Google Tag Manager

  1. En tu contenedor de GTM creá una etiqueta nueva con la plantilla de la comunidad para el píxel de Meta (o una etiqueta HTML personalizada con el código base).
  2. Pegá el ID del conjunto de datos y dispará la etiqueta en todas las páginas.
  3. Creá una etiqueta por evento (Lead, Contact, Schedule) con su activador: envío de formulario, clic en el botón de WhatsApp o visita a la página de gracias.
  4. Publicá el contenedor y probá con el modo vista previa de GTM.

GTM web solo instala el píxel. Para la API de conversiones por esta vía hace falta un contenedor de servidor (server-side GTM), con su propio hosting.

Opción 5: integraciones de socios y la configuración de Meta

Shopify, Wix, WooCommerce y muchos CRM tienen integración directa: la elegís en Conectar datos y configura píxel y API juntos. Desde 2026, Meta también ofrece una configuración de la API de conversiones habilitada por Meta para webs, sin costo y en pocos clics.

¿Qué eventos estándar conviene medir en una pyme?

Meta tiene una lista de eventos estándar: nombres fijos que el algoritmo entiende sin explicación, como Lead o Purchase. Usá esos antes que eventos personalizados. La regla es medir el paso más cercano a la venta que tenga suficiente volumen.

RubroEventos recomendadosPara optimizar
Concesionarias y talleresViewContent (ficha de unidad), Contact (clic a WhatsApp), Lead (formulario), Schedule (turno)Lead o Schedule
FinancierasContact, Lead, CompleteRegistration (solicitud enviada)Lead calificado
SaludContact, ScheduleSchedule, con cuidado (ver errores)
Servicios B2BContact, LeadLead
Tienda onlineViewContent, AddToCart, InitiateCheckout, PurchasePurchase

Elegir mal el evento sale caro. En el caso de Tu Préstamo Genial, la campaña buscaba a quien escribiera más barato, no a quien calificara para un crédito. Si tus campañas van a WhatsApp, te sirve leer cuándo conviene una campaña a WhatsApp y cuándo un formulario, porque cambia qué se mide con el píxel y qué mide Meta por su cuenta.

¿Qué es la deduplicación y cómo se configura?

La deduplicación es el proceso por el que Meta detecta que un evento del píxel y uno de la API son la misma acción, y cuenta uno solo. Sin ella, cada consulta aparece dos veces.

Para que funcione, los dos envíos tienen que compartir:

  • El mismo nombre de evento: Lead en el píxel y Lead en el servidor. Si uno dice "Lead" y otro "Formulario", no se cruzan.
  • El mismo ID de evento: el eventID del píxel tiene que ser idéntico al event_id de la API. Por ejemplo: fbq('track', 'Lead', {}, {eventID: 'form-123'});
  • El mismo conjunto de datos y una ventana de 48 horas: si llegan al mismo ID dentro de ese plazo, Meta descarta el duplicado.

Las integraciones de socios y el plugin de WordPress generan ese ID solos. En una instalación a medida, pedíselo al desarrollador.

¿Cómo probar el píxel con Probar eventos?

  1. En el Administrador de eventos, abrí Orígenes de datos en la barra lateral y elegí tu conjunto de datos.
  2. Entrá a la pestaña Probar eventos.
  3. En Probar eventos del navegador, escribí la URL de tu sitio y hacé clic en Abrir sitio web.
  4. Navegá como un cliente: entrá a una ficha, completá el formulario de prueba, tocá el botón de WhatsApp.
  5. Volvé a la pestaña de Meta. Cada acción tiene que aparecer con su nombre. Si llega por navegador y por servidor, debería figurar como deduplicada.
  6. Para probar la API, copiá el código de prueba que muestra la misma pestaña y cargalo en tu integración o pasáselo al desarrollador (parámetro test_event_code).

Desactivá el bloqueador de anuncios mientras probás. También sirve la extensión Meta Pixel Helper, disponible para Chrome y Edge, que muestra qué eventos dispara cada página.

¿Qué es la calidad de coincidencia de eventos y cómo subirla?

La calidad de coincidencia de eventos (Event Match Quality) es una puntuación de 1 a 10 que indica qué tan bien la información de cliente que mandás permite asociar un evento con una cuenta de Facebook o Instagram. Solo los eventos que coinciden sirven para atribuir y optimizar. Meta recomienda apuntar a 6 o más. La ves en el resumen del conjunto de datos.

Para subirla:

  • Activá la coincidencia avanzada automática.
  • Mandá por la API los datos que tengas: email, teléfono, nombre, IP y navegador, y un ID de cliente propio (external_id).
  • Pasá también las cookies fbp y fbc si tu integración lo permite.
  • Enviá los eventos en el momento, no en lotes días después.

¿Cuáles son los errores más comunes con el píxel de Meta?

  • Píxel instalado dos veces: en el código y en un plugin, o en el tema y en GTM. Duplica todo.
  • Nombres distintos entre píxel y API: rompen la deduplicación.
  • Conectar dos API a la vez, como Tienda Nube y el Gateway. Ensucian los datos.
  • Optimizar a un evento sin volumen: si tenés pocas ventas por semana, la campaña no aprende. Empezá por un paso anterior.
  • Contar como Lead un clic: un clic en WhatsApp es intención (Contact), no un cliente potencial.
  • Datos sensibles de salud: Meta restringe qué pueden compartir los anunciantes de salud y bienestar, tanto por píxel como por API. Evitá nombres de tratamientos en URLs, parámetros o eventos. Si sos de ese rubro, sumá lo que contamos en marketing para odontólogos.
  • No volver a revisar: un cambio de web o de plugin rompe la medición sin avisar.

Si ya tenés todo instalado y los anuncios igual no traen ventas, el problema puede estar en otro lado. Lo repasamos en por qué tus anuncios no venden.

¿Lo hago yo o lo delego?

Con Tienda Nube o el plugin de WordPress, lo podés dejar andando en una tarde con esta guía. Con sitios a medida, varios formularios y CRM, conviene delegarlo. Preguntas frecuentes

¿El píxel de Facebook y el píxel de Meta son lo mismo?

Sí. Es la misma herramienta con otro nombre. Hoy, dentro del Administrador de eventos, Meta lo muestra como un conjunto de datos, que agrupa los eventos del píxel y los de la API de conversiones.

¿Necesito la API de conversiones si ya tengo el píxel?

Si invertís en anuncios con objetivo de ventas o de clientes potenciales, sí. El píxel depende del navegador y pierde eventos por bloqueadores y cookies. La API de conversiones los manda desde el servidor y completa lo que falta.

¿Cuánto tarda en verse un evento en el Administrador de eventos?

En la pestaña Probar eventos aparece casi en tiempo real. En el resumen general puede tardar más. Si no ves nada después de unos minutos, revisá bloqueadores de anuncios y que estés mirando el conjunto de datos correcto.

¿Puedo tener el píxel instalado dos veces?

No conviene. Si el mismo píxel está en el código del sitio y también en un plugin o en Google Tag Manager, cada evento se cuenta dos veces. Elegí un solo método por píxel y desactivá el resto.
